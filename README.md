# Beauty designs

10 дизайн-концепций для бьюти-салона + финальная демо.

## Что внутри

| Путь | Что |
|---|---|
| `index.html` | Галерея 10 направлений — карточки с палитрой, шрифтами, идеей анимации |
| `demo-01-brutal/` | Вариант 1 — нео-брутал (pink/lime/black, жёсткие блоки) |
| `demo-04-kinetic/` | **Финал** — кінетична типографіка: бордовый, светло-графитовый фон, 3D-наклон заголовка за мышью |
| `ТЗ-designs.md` | Техзадание: этапы, что уже сделано, скиллы, критерии |
| `shots/` | Скриншоты (десктоп / мобильный / 3D-наклон) |

## Превью

- Галерея: [`index.html`](index.html)
- Финал: [`demo-04-kinetic/index.html`](demo-04-kinetic/index.html)

## Технологии

Статический HTML/CSS/JS, без фреймворков и сборки.
Google Fonts: Archivo Black, DM Mono, Onest.
Адаптив 390 / 1440, `prefers-reduced-motion`, контраст по WCAG AA.

## Локальный запуск

Просто открой `index.html` или `demo-04-kinetic/index.html` в браузере.
Либо: `python3 -m http.server` в этой папке.
